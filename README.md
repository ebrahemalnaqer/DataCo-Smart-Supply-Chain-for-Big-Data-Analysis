# DataCo Smart Supply Chain - NTI Award-Winning Project

## 🎯 Project Overview
This project focuses on optimizing supply chain operations by analyzing over 180k+ records. It was recognized as the **"Best Graduation Project"** in the NTI Data Analysis track. By leveraging Python and SQL, I identified significant revenue leaks and formulated data-driven strategies to recover nearly $1M.

## 💡 Key Analytical Findings
* **Revenue Recovery:** Identified $898K in revenue loss due to 1-day shipping delays.
* **Discount Optimization:** Discovered a 10%–13% "Golden Ratio" for discounts, yielding $300K in projected savings.
* **Fraud Detection:** Uncovered a 100% correlation between high-demand product fraud and "Bank Transfer" payment methods.
* **Strategic Reallocation:** Performed geographic price sensitivity analysis to optimize marketing budget allocation.

## 🛠️ Technical Stack
* **Languages:** SQL (Window Functions, CTEs, Joins), Python (Pandas).
* **Visualization:** Power BI (Interactive Dashboards, KPI Tracking).
* **Modeling:** Star Schema Data Modeling, ETL Pipeline Design.
